Yesterday I learnt about Networking Concepts.

1. Modem - Which modulates and demodulates the signal 
2. Hub - A networking device which helps in creating network using cables for multiple devices. It is a simple non-intelligent device which receives data from one source and transfer it to all the connected device.
3. Switch - Switch is similar to Hub but it is more intelligent because switch will know if it is receiving data packate from one device so where should it transfer with the help of MAC address table. It maps the mac address with the port and transfer the data packate to the dedicated device.
4. Router - Router as the name suggestes helps in routing the data. It connected one network to the another network. Router uses IP address to transfer data.
